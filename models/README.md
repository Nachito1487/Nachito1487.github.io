# Temporary body reference

Source: Cesium Man by Cesium, Khronos glTF Sample Assets.
https://github.com/KhronosGroup/glTF-Sample-Assets/tree/main/Models/CesiumMan
License: CC BY 4.0, https://creativecommons.org/licenses/by/4.0/
Retrieved 2026-10-13. Original included as cesium-man.glb; license notice retained.

body-reference.glb is an ABCuerpo adaptation: static bind-pose geometry, no animation or skinning, neutral material replacing the branded texture, world axes aligned Y-up and face +Z. The underlying mesh is unchanged. It is a clothed technical reference, not an anatomical or final brand model. It does not depict hair, teeth or genital detail. Hotspots identify regions only.

Replacing the mesh requires remapping hotspot coordinates and checking front/side/back visibility. Hidden hotspots are based on their facing normal; this is not full mesh occlusion detection. No vendor account, paid asset or runtime CDN required. Renderer: @google/model-viewer 4.3.1, Apache-2.0; its internal renderer includes Three.js, without an additional bespoke Three.js integration.
